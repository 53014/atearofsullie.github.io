새로운 기록

날짜와 글을 작성한 뒤 파일을 내려받아 GitHub의 _posts 폴더에 올리면 게시됩니다.

다운로드한 뒤 게시하는 방법

  1. GitHub 저장소 atearofsullie.github.io를 엽니다.
  2. _posts 폴더에 들어갑니다.
  3. Add file → Upload files를 눌러 방금 받은 Markdown 파일을 올립니다.
  4. Commit changes를 누르면 잠시 후 기록 목록에 나타납니다.
